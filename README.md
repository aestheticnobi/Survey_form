# App User Survey Form

A clean, light-weight web application form designed to collect customer feedback, demographics, and usage habits for mobile and web applications.

## Features
- **User Profile Fields:** Collects standard user details including name, phone number, address, and email.
- **Single-Selection Radio Groups:** Grouped input options for demographic details (Gender) and usage duration.
- **Feedback Collection:** Open text area for qualitative customer reviews and feature requests.
